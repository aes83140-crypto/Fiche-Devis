Administration

Les techniciens enregistrés ici sont proposés automatiquement dans toutes les fiches : devis, Relevé Vantaux SAV, rideaux métalliques et contrat de maintenance.

Statistiques d'utilisation

Chaque fiche envoyée ou téléchargée est comptée automatiquement, sur toutes les tablettes, sans aucune action des techniciens.
Espace partagé : statistiques + listes (à configurer une seule fois)
Cet espace sert à deux choses : compter automatiquement les fiches envoyées depuis toutes les tablettes, et permettre à chaque responsable de modifier la liste des techniciens avec le seul code d'accès. Il se crée gratuitement en quatre étapes :
1. Sur script.google.com → Nouveau projet, collez le code ci-dessous.
2. Créez une feuille Google Sheets, copiez son identifiant (dans son adresse, entre /d/ et /edit) à la place de ID_DE_LA_FEUILLE.
3. Déployer → Nouveau déploiement → type Application web, « Exécuter en tant que : moi », « Accès : tout le monde ».
4. Copiez l'adresse entière fournie par Google (elle commence par https://script.google.com/macros/s/ et finit par /exec) dans le champ ci-dessous, puis Enregistrer.

Listes communes à tous les appareils

Les autres responsables n'ont besoin que du code d'accès : dès que l'espace partagé est configuré (plus bas), leurs ajouts et suppressions de techniciens sont diffusés à toutes les tablettes, sans jeton GitHub.
Les listes sont lues dans le fichier listes.json du dépôt. Une fois la publication configurée ci-dessous, le bouton Publier en ligne met le fichier à jour tout seul : plus aucun dépôt manuel.
Configurer la publication (une seule fois, sur votre PC)
Ces réglages restent sur cet appareil, les techniciens n'ont rien à saisir.

1. Dépôt : ouvrez votre projet sur github.com, l'adresse ressemble à github.com/moncompte/mon-projet \u2014 recopiez cette partie en gras.
2. Branche : laissez main (c'est le cas de presque tous les dépôts ; si le vôtre affiche « master », écrivez master).
3. Jeton : c'est le mot de passe qui autorise cette page à mettre le fichier à jour. Sur github.com, cliquez votre photo en haut à droite → Settings → tout en bas Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Donnez-lui un nom, choisissez votre dépôt dans Repository access, puis dans Permissions → Repository permissions réglez la ligne Contents sur Read and write. Validez : GitHub affiche une longue suite de caractères \u2014 copiez-la ici. Elle ne s'affiche qu'une fois.
